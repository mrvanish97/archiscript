# Next-version backlog after the 0.7 semantic rewrite

## Automatic global Cone/Expression coverage

**0.7 status: NOT AUTOMATICALLY VERIFIED.**

Prove that every finite linear Expression generated from the closed primitive
inventory, including paths beginning inside cycles and justified tensor imports,
is covered by at least one declared one-Cause Cone. The current certificate
quantifies over derived local contexts and checks complete terminal boundaries;
it does not prove this additional universal union-of-Cones property.

A walk over nominal VDP values is insufficient: equal denotations do not identify
occurrences, and recursive cross-Cone supplier derivations retain histories.
A candidate symbolic checker needs a precise `GeneratedExpression`/`InCone`
relation, induction/coverage proof, disconnected-cycle and omitted-generator
negative cases, and a sound connection to the existing root-instance semantics.
Real-world inventory completeness remains an author assumption even after this
relative theorem is proved. Do not replace it with a selected family or list.

## Optional analysis improvements

- Derive maintainable finite exact abstractions for larger provenance-sensitive
  fragments. Prove their query agreement; do not infer finite state from finite
  VDP members. The current bounded saturation returns an exact result only once
  closure is checked. SCC/worklist optimization needs a preservation proof.
- Provide ergonomic proof combinators for universal context and terminal
  occurrence obligations without removing required proof fields.
- Profile provenance-cache closure and catalog lookup on at least two realistic
  inventory sizes before choosing an index or worklist optimization. Repeated
  full-list scans are a possible cost, not a measured slowdown. Any replacement
  must preserve normalized histories, source positions, closure checks and proof
  coverage; retain small semantic regressions independently of benchmark sizes.
- Improve witnessed diagnostics for nondecidable semantic contracts while
  preserving the distinction between an unsolved proof and an invalid model.
- Explore a frontend only after the semantic API is reviewed. No Markdown parser,
  generated theorem language, scheduler, resource calculus or implementation
  conformance claim is implied by this backlog.

The 0.7 shared-target correction is implemented, not deferred here: finite
normalized-history bases require seeds, full-source closure and realizations;
shared suffixes retain distinct histories. Future analysis work may broaden
that supported fragment to more general cyclic
observation quotients, with soundness/completeness proofs. None of that work
reintroduces named unique VDP uses, cloned graphs or generator-output uniqueness.

The 0.7 input-source and no-observation cases are also implemented: each declared
generator has a mandatory source-accounting obligation, and each Cause has an
observable or explicitly unobservable status. Infinite root-instance types do
not require infinite caches: only each concrete Cause's canonical origin is
supported. Composition of repeated external invocations would be a separate
future extension, with its own semantics.
