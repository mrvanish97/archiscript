## 2. Executive summary and corrected design

The 0.6.0 primary classifier representation has been replaced by semantic
Subdomains, proof-carrying decompositions and predicate-backed VDPs. The
classifier is derived from coverage and uniqueness. Correct existing algebra
has been ported. Nonlinear morphism syntax is now `Presentation`; `Expression`
means a finite linear chain over the registered primitive inventory and nominal
objects.

The new reference semantics retains exact root instances and complete finite
producer derivations. It includes arbitrary finite cycle traversals and recursive
cross-Cone suppliers. Input contexts are derived from actual suppliers, and
certificate construction requires universal proofs over these contexts. Full
Cone Effects require exact reachable/admissible tuple agreement, independently
derived incoming images, nonempty reachability, complete terminal boundaries
and complete producer-derived terminal coordinates, including shared targets.

Tensor remains the full Cartesian product. A reachable or admissible relation
may be a proper subset. Several outgoing Operations are non-exclusive possible
structural consequences; no execution, scheduling, fairness or completion claim
is introduced. Partial mappings remain mathematical undefinedness. Production
code conformance and external semantic truth are separate obligations.

The implementation follows the [0.7.0 handoff](../../archiscript-docs/chapter-1/stage-3/archiscript-0.7.0-lean-core-rewrite-handoff.md),
including its later corrections to the older Stage 3 vocabulary and universal
surjectivity proposals, and the shared-target/join correction merged in
[docs PR #4](https://github.com/mrvanish97/archiscript-docs/pull/4), commit
`4e0e8431f49efb0b3038942e6167f88381940611` (§7.3.1, §10.5, §16.6–7). No `.arch.md` language, compiler, new tensor-site
ontology, generated theorem system or approval-based mathematical certificate
has been added.

## 3. Detailed semantics and public API

### Semantic regions and decompositions

[`Subdomain.lean`](../ArchiScript/Subdomain.lean) defines `Domain`,
`DomainDerivation`, `Subdomain` and `SemanticSplit`.

- A `Subdomain α` supplies its base, parent derivation, exact meaning,
  containment, definition derivation and actual inhabitant. `root`, `child`
  and `remainder` preserve these obligations. Relative complement is within
  the proved parent. Empty intermediate predicates remain legitimate.
- Every declared `SemanticSplit parent` has finite nonempty indices, child
  Subdomains, child containment, parent coverage and sibling disjointness.
  `SemanticSplit.complement` and `SemanticSplit.refine` derive the appropriate
  proofs. Independent trees may overlap; no universal taxonomy is imposed.
- Opaque derivations retain a nonempty reason. Such metadata does not create
  an inhabitant or prove an external business claim.

[`Partition.lean`](../ArchiScript/Partition.lean) keeps the actual `Partition`
structure and exposes `VDP` as its semantic vocabulary alias. `members` contains
actual Subdomains; `coverage` and `disjoint` are mandatory. Member indices have
finite and nonempty evidence. `Partition.ofSplit` requires the chosen parent
to cover the carrier; a split over successful inputs alone cannot establish
coverage of a broader URI carrier. `Partition.closed` supports legitimately
closed finite enumerations without inventing a classifier-first boundary.

`member_nonempty`, `member_unique`, `classify_spec` and `self_member` establish
the representation facts. `classify` is classical and noncomputable; optional
`lookup` uses actual predicate decisions and member enumeration. Infinite
carriers do not need enumeration. `PartitionIso.preserves` now states semantic
membership correspondence; `classify_commutes` follows from that correspondence.

### Operations and expressions

[`Operation.lean`](../ArchiScript/Operation.lean) retains
`run : X.MemberIndex → Option Y.MemberIndex`. Identity, composition, tensor,
branches and the valid laws remain. `image`, `image_comp` and `single_output`
expose image semantics and functional determinism. Neither totality nor
surjectivity is imposed. A function cannot assign two different outputs to
the same source member; a real distinction of that kind needs a refined model.

[`Expression.lean`](../ArchiScript/Expression.lean) defines `Generators`
with a finite complete name inventory, nominal object type and typed endpoints.
`Expression.identity`, `Expression.step`, `append`, `denote`, `denote_append`
and `image` describe linear paths. Identical VDP denotations do not make
different nominal ports composable. There is no `Expression.tensor` or
`Expression.copair`. Actual tensor suppliers are recorded separately by the
typed provenance terms below; a branchy supplier term is not a single Expression.

### Declared architecture and reference reachability

[`Architecture.lean`](../ArchiScript/Architecture.lean),
[`Provenance.lean`](../ArchiScript/Provenance.lean) and
[`Consequence.lean`](../ArchiScript/Consequence.lean) provide:

`World` fixes values of external root instances. It does not assign fixed values
to all later cyclic observations. Reference evaluation quantifies over **all
finite terms**, rather than a hand-maintained list. Operation histories can
therefore be unbounded even when member alphabets are finite. `context` and
`effectContext` are explicit semantic availability/correlation assumptions;
their real-world interpretation remains the author's responsibility.

`evaluate_of_assignment` is a reusable conditional invariant lemma requiring
root agreement, every generator equation and availability. It imposes no
stationary-value rule on arbitrary cycles. `Evaluates.deterministic`,
`Evaluates.supplier` and `defined_consequence` prove the corresponding reference
facts. The last theorem includes every defined output of an available,
reachable generator input; it asserts no physical execution.
`effect_image_of_assignment` and `effect_projection_of_assignment` factor the
stationary interpretation's full Effect image and projections through explicit
premises. They avoid repeatedly unfolding a concrete signature during proof
elaboration and do not impose stationary behavior on other models.

Typical migration: replace a record's `classify := ...` with declared semantic
`members`, `coverage` and `disjoint`, then use derived classification only in
proofs or optional decidable lookup for computation. `PartitionIso` constructors
now supply `preserves`; a classifier-commuting field is insufficient. Rename old
`Expression.tensor`/`copair`/families/normalization code to `Presentation`; declare
new linear `Expression`s over registered primitives. Import companion workflow
modules explicitly. Constructing `CertifiedDeclaredArchitecture` requires all
proof fields; passing a raw `DeclaredArchitecture` does not typecheck. Previous
0.7 draft users replace `terminalOccurrencesFaithful` with
`effectAnalysis : ProvenanceAnalysis cyclicBoundary` and its `effectCoverage`
proof. Effect shapes are indexed by derived histories, not merely node lists;
reachable suppliers additionally supply `EffectProvenance`. Many-to-one generator
outputs are legitimate and need no injectivity proof.

The migration-only [`ProofSupport.lean`](../ArchiScriptExamples/ProofSupport.lean)
helper accepts independently stated regions, candidate lookup, proved lookup
equivalence and witnesses. It builds the actual predicate-backed members.
It does not expose the old classifier constructor as a public proof bypass.

## 5. Lean proof and trust evidence

[`Reachability.lean`](../ArchiScript/Reachability.lean) defines the reference
`Reach` inductively, with `least`. `FiniteAnalysis` requires an explicit complete
enumeration of **semantic configurations**, decidable seeds/steps and equality.
`compute_sound`, `seeds_in_compute` and `compute_complete_of_closed` prove bounded
saturation sound and complete once the entire computed state set is closed.
`certify fuel` returns an `Exact` result only after that closure test. `none`
means this attempt did not certify closure; it is not an invalid-architecture
verdict. No universal iteration bound or automatic finite-history assumption is
claimed.

`Exact.membership` proves membership iff reference transition reachability.
`ExactAbstraction.equivalent` must separately connect a finite query analysis to
the architectural reference relation. `certified_abstraction` combines these
proofs. The swap example supplies `closure_exact` and `computed_effect`; the
mutual-Cone example supplies `closure_exact` and `computed_joint`. These are
model-specific exact query abstractions, not a universal SCC implementation or
an assertion that provenance terms themselves form a finite state space.

[`Verification.lean`](../ArchiScript/Verification.lean) proves
`checkAgreement_correct` with an exhaustive full-tuple enumeration premise.
`missing_witness`, `unexpected_witness` and `unpartnered_witness` retain actual
counterexamples, including the necessary exhaustive partner enumeration for
the orphan conclusion. No pairwise substitute is used.

Closed concrete tagged certificates are provided by `SimpleCone.certified`,
`CyclicCone.certified`, `CorrelatedJoin.diagonalCertified`,
`CorrelatedJoin.constantCertified`, `CrossCone.certified`,
`MutualCones.certified`, and `SharedTargets.equalImages`, `differentImages`,
`correlatedImages`, `sharedSuffix`, `differentSuffix`; the public smoke provides
another independent certificate. `ContractAudit.independent` is a positive audit
control. `SharedTargetJoin.input_valid` proves every input-context obligation,
including the supplied C ⊗ C → R, without claiming a complete Cone certificate. Reusable theorem/factory parameters
are not mislabeled as supplied concrete assumptions.

The release audit inspects compiled **transitive dependencies of every project
declaration**, including private declarations, not a selected certificate list.
It traverses the checked public/example/test import closure, including private
constants. Its only allowed axioms are `propext`, `Classical.choice` and `Quot.sound`.
Direct/transitive `sorryAx`, unauthorized custom axioms and extra computation
axioms are rejected. Tagged concrete certificates must have the closed
`CertifiedDeclaredArchitecture` type without unsupplied parameters.

The review reproduced a real enforcement gap: the previous tagged-only audit at
`f42f50852b1693158597ac47b99bdeae97a9fe3c` accepted a complete, untagged certificate
whose indirectly aliased input contract was `SimpleCone.model.reachInput`. The
historical checker was replayed locally against that same complete certificate;
it passed. The revised checker rejects its installed `admissibleInput` field.
It exposes the actual records and inspects both input/effect contracts for
**every closed `DeclaredArchitecture` and `CertifiedDeclaredArchitecture`
declaration in those checked imports, regardless of tags**. It follows inline, indirect and opaque aliases
and rejects closed records it cannot inspect. Conditional factories are inspected
at their closed instantiations; tags additionally check standalone predicates.
Four complete-certificate regressions cover untagged/indirect input, inline input,
opaque input/record and untagged effect contracts. Each allows only
`CONTRACT_AUDIT` errors; a type error or `sorryAx` rejection cannot count as success.

The constructor by itself cannot prove independent authorship. The mandatory
release audit checks installed implementation dependencies; no syntactic audit
can prove independent human intent or rule out extensionally equivalent
independently written formulas. External truth, model adequacy and omitted real-world
requirements remain outside Lean's proof boundary. Conventional axioms and
conditional theorem premises remain visible in the JSON audit.

The provenance basis is also a kernel obligation. `Seeded` includes every
allowed root history; `Closed` expands every declared generator over its full
source history product; `Realized` decodes every cached history into an actual
typed local-root derivation with the same normalized provenance. `complete` and
`sound` prove both directions. `terminal_positions` covers every finite supported
boundary derivation, and `effect_realized` reconstructs suppliers without claiming
value reachability. The optional `derive_provenance([roots], fuel)` only produces
cached data; too little fuel fails closure. Repeated cache rows do not add
coordinates. Finite complete roots and a finite closed normalized-history basis
are explicit supported-fragment conditions, not consequences of finite members.

The executable gate additionally replays the kernels with explicit module
names. Exact final command results and declaration counts are recorded in
section 11 and in `.lake/reports/`; these reports are CI artifacts, not approval
records or assumptions accepted by the mathematical core.

## 6. Global Cone/Expression coverage

**Global Cone/Expression coverage: NOT AUTOMATICALLY VERIFIED.**

The public certificate name is deliberately `CertifiedDeclaredArchitecture`.
Its `coverageStatus` returns this exact string. It proves universal obligations
for derived actual input contexts, every declared Cause's Cone Effect and
terminal boundaries. It does not prove the additional union-of-Cones theorem
over every generated linear Expression, including expressions beginning inside
cycles with contextual tensor imports.

A nominal connectivity check would lose exact root identity and recursive
supplier provenance. A selected family would omit arbitrary finite cyclic paths.
No simple automatic symbolic coverage checker with the required semantic
connection was implemented. The handoff permits deferring precisely this
automatic universal guarantee. [0.8.0 backlog](../plans/0.8.0.md) records the
required generated-expression relation, symbolic proof, disconnected-cycle and
omitted-generator regressions and exact root/provenance connection. A future
checker still cannot discover undeclared real-world Operations or Causes.

## 7. Tensor, cycles, cross-Cone verification and design decisions

| Issue | Implemented semantics, evidence and limit |
| --- | --- |
| Partiality (B1) | `Option.none` is undefinedness; `Operation.image` and partial-map tests preserve it. No mandatory execution interpretation. |
| Context and availability (B2/B6) | Full supplier histories and allowed worlds precede the current join. `incoming` is independent of accepted tuples. `InputValid` checks both exact full tuples and projections. |
| Typed cyclic anchors (B3) | `Term.CycleBoundary` requires a real return with one entry and nonzero Operations. `CyclicCone` starts inside a loop; `CrossCone` and `MutualCones` supply typed contextual returns. Missing anchors/suppliers fail. |
| Repetition and terminal identity (B4) | One C or E can have multiple producer-derived coordinates. SharedTargets certifies equal/different images and a single shared h;k. SharedTargetCycles preserves two entries while aggregating any number of actual marked returns. CollapsedEffect/Basis reject lost provenance, not the valid many-to-one graph. |
| Global coverage (B5) | Explicitly unverified and deferred, as section 6 states. No selected list substitutes for it. |
| Cross-Cone cycles (B7) | Reference terms recurse through the full generator inventory. `CrossCone.input_valid` accounts for an external alternating factor; `MutualCones.input_valid` and `computed_joint` justify the joint two-Cone query. No fictitious topological order is imposed. |
| Full tensor vs subsets (B8) | Products keep all members. Common-source diagonal and constant-supplier contracts are proper subsets with exact upstream projections. |
| Zero/unreachable effects (B9) | Certificate construction requires `causeNonempty`; `CertifiedDeclaredArchitecture.hasCone` proves there is an actual valid Cone. `InputStatus.unreachable` requires empty incoming images, empty Reach and empty contract. Verified uses require a witness. `ConeValid` requires nonempty boundaries and a reachable full Effect. Source-only/empty-effect declarations do not acquire a vacuous complete-effect certificate. |
| Independent contracts (B10) | Named domain predicates are authored separately; audit rejects semantic implementation dependencies. Human semantic independence is explicitly outside what an axiom/dependency check can establish. |
| Stage 2 and opaque boundaries (B11) | Eight URI regions are derived from complete parent splits. Correspondence to actual URI/filesystem observations remains explicit. Uninhabited opaque regions cannot be registered by prose. |
| Additional category machinery (B12) | Existing proved monoidal/coproduct/isomorphism laws suffice; no speculative trace or universal iteration ontology is introduced. |

The terminal policy follows handoff §7.3.1: sharing a target, member, image or
suffix does not join results. One authored graph and automatically derived typed
histories suffice; there are no mandatory unique VDP uses or cloned downstream
Operations. `effectCoverage` establishes the complete supported provenance basis;
`EffectProvenance` prevents a supplier from occupying the wrong coordinate.
A true join is a separately declared, fully supplied tensor-source Operation,
with its own full-tuple/projection proofs. The analytical Effect product creates
no Operation. A typed cyclic return marker separately identifies the repetitions
aggregated at one observation boundary. `BoundariesComplete` proves structural
access to boundaries. None of these local guarantees is the deferred universal
union-of-Cones coverage theorem.

The swap loop proves cumulative member closure `{false,true}` and
`powers_do_not_stabilize`. Delayed-terminal tests prove an unchanged terminal
projection cannot justify stopping saturation. `histories_are_not_enumerable`
proves that finite member alphabets do not enumerate unbounded generation counts.
There is no runtime termination, fairness, consumption, storage or scheduling
conclusion.

## 12. External assumptions, limitations and migration boundaries

- Carrier choice and correspondence to real external possibilities are author
  assumptions. Lean proves the stated regions cover the chosen type, not that
  the type includes every business/network/filesystem possibility.
- Reference worlds and availability predicates are explicit modeling inputs.
  Production persistence, ordering, transactions, resource effects, liveness and
  implementation conformance have no implicit semantics.
- `CertifiedDeclaredArchitecture` ranges over declared contexts and Cones. It
  proves no universal generated-Expression coverage theorem. A raw workflow
  architecture, selected family, draft pack or approval is not that certificate.
- The complete-effect API requires a nonempty Cause inventory and excludes empty terminal inventories and
  zero-reachable full Cone Effects. Unreachable **input** contexts have a separate
  proved status. A broader source-only reporting API is future ergonomics, not
  a vacuous tensor-unit success in this release.
- Natural-terminal producers may share nominal nodes and downstream graphs.
  Coordinates are derived histories, not authored slots. Explicit typed cyclic
  boundaries aggregate repetitions of their matched return routes while keeping
  distinct entry producers. No tensor coordinate per dynamic event is claimed.
- Complete certification currently requires finite root enumeration and a finite
  closed, realized normalized-history basis. Finite VDP members alone do not
  establish that condition. More general observation quotients/roots need
  additional exactness work; the reference relation still includes all finite
  derivations.
- Exact finite computation needs complete configurations and model-specific
  abstraction agreement. Infinite provenance histories are supported by the
  reference relation, not automatically enumerated by the finite analyzer.
- The contract audit is a transitive implementation-dependency check, not proof
  that an independently written business judgment is correct. Conventional
  classical axioms remain trusted and visible; custom axioms are not accepted.
- Legacy examples preserve their actual algebraic/semantic proof scope. They
  have not all been upgraded to complete Cone certificates. New certificates
  demonstrate the new required obligations explicitly.

There is no remaining demonstrated contradiction requiring an architect answer
before this PR can be reviewed. The explicit boundary policies and deferred
optional coverage theorem are reviewable design choices, not silently invented
runtime behavior.
